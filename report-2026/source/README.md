# СГЮА — цифровой отчет 2026

Пространственный отчет кафедры теории государства и права по шести направлениям Программы развития. Контрольный срез: 01.09.2026.

Все 40 строк показателей и 7 комментариев перенесены из исходного PDF (`public/report-2026.pdf`). Отсутствующие и годовые значения сохранены без подмены нулем.

CSS 3D, плавный pointer-follow tilt через requestAnimationFrame, раскрытие комментариев внутри показателя. Tilt отключен на touch-устройствах и при prefers-reduced-motion.

## Запуск

Node.js 22.13 или новее.

```sh
npm install
npm run dev
npm run typecheck
npm run build
```

GitHub Pages публикует корень репозитория `ANTOVIUM/sgua` существующим workflow. Готовая сборка отчета размещена в `report-2026/`, исходники — в `report-2026/source/`.

После изменений выполните `npm run build` из папки `source`, скопируйте содержимое `docs/` на один уровень выше в `report-2026/` и включите обновленные файлы в коммит. Сервер и база данных не требуются.
