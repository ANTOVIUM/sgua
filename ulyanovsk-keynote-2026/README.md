# Научное выступление М.А. Антонова

«Место презумпции недобросовестности в механизме защиты гражданских прав».
Поволжский юридический конгресс, Ульяновск, 10 октября 2026 года.

Основная линия: 8 сцен и 26 смысловых состояний, расчетный регламент 10 минут.
Отдельный резерв: 10 тем для ответов на вопросы.

## Запуск

Открой `dist/standalone.html` в Chrome или Edge. Шрифт, стили, текст и графика
встроены в один файл; подключение к сети не требуется. Клавиша `P` открывает
окно докладчика. Открывай два окна друг из друга, чтобы сохранить резервный
канал синхронизации при работе с локальным файлом.

Если браузер ограничивает взаимодействие файлов с диска, запусти:

```sh
python dist/start-local.py
```

Локальный сервер слушает только `127.0.0.1:8765`; интернет ему не нужен.
Экран аудитории: `/present/`, экран докладчика: `/presenter/`.

Для разработки доступны `node dev-server.mjs --port 4173` и `node build.mjs`.
Внешние пакеты для работы презентации не нужны. Сборка создает маршруты,
автономный HTML и Service Worker. В автономном HTML Service Worker не используется.

Публичный адрес и сведения о проверенной публикации приведены в `publication.json`
офлайн-комплекта. Исходники и production build размещены в отдельной папке
`ulyanovsk-keynote-2026` ветки `ulyanovsk-keynote-20261007` репозитория `ANTOVIUM/sgua`.

## Управление

| Клавиши | Действие |
|---|---|
| ArrowRight, Space, Enter, PageDown | Следующий смысловой шаг |
| ArrowLeft, PageUp | Предыдущий шаг |
| F | Полный экран |
| P | Окно докладчика |
| T | Старт или пауза таймера |
| A или Q, затем 1-9 или 0 | Открыть резервную тему 1-10 |
| Esc | Закрыть меню, вернуться из резерва |
| M | Сокращенное движение |
| G | Плоская геометрия |
| B или точка | Черный экран |
| Home | Первая сцена |
| H | Схема управления |

F11 служит резервным полноэкранным режимом браузера. Перед первой фразой:
Home, сброс таймера в панели докладчика, полный экран, затем T.
При входе в резерв таймер приостанавливается. Esc возвращает к сохраненному
основному шагу, а T отдельно возобновляет таймер.

## Состав

- `dist/` - production build со всеми локальными ресурсами.
- `dist/standalone.html` - автономная интерактивная версия.
- `dist/static/index.html` - HTML без скриптов, 26 основных и 10 резервных страниц.
- `dist/fallback.pdf` - 36 страниц, по одному смысловому состоянию на страницу.
- `dist/content.js` - речь, заметки, резерв и проверенные нормативные ссылки.
- `dist/app.js` - навигация, графика, таймер, синхронизация.
- `dist/style.css` - композиция, типографика и движения.
- `dist/assets/OFL.txt` - лицензия Golos Text SIL OFL 1.1.
- `scripts/make_materials.py` - сборка документов и резервов из данных и проверенных кадров.
- `scripts/check.html` - инструмент проверки; временно копируется в `dist/check.html` для локального запуска.

Документы и результаты проверки включены в папки `documents/` и `verification/`
офлайн-комплекта. У речи 1160 слов; расчетный темп после раскрытия сокращений -
125,2 слова в минуту плюс 32 секунды пауз. Индивидуальная длительность выступления
автора не измерялась.

## Научные границы

Пункт 3 статьи 1 ГК РФ обозначает нормативный стандарт; пункт 5 статьи 10 -
общее предположение. Специальная презумпция показана как исключение из общего
презумптивного режима и вспомогательное средство охранительной направленности.
Альтернативные основания пункта 2 статьи 434.1 и пункт 19 Пленума ВС РФ № 7
разграничены с обычным доказыванием недобросовестности.

Модель использования положения потерпевшего по статье 179 обозначена как
авторское предложение de lege ferenda. Действующий пункт 3 статьи 179 прямо
не закрепляет предлагаемую презумпцию. Остальные условия защиты сохраняют
самостоятельное значение.

## Границы технической проверки

Проверен Chrome 154.0.0.0: 180 состояний при пяти внутренних размерах экрана,
клавиатурная навигация, быстрые переходы, синхронизация, таймер, резерв,
перезагрузка, сокращенное движение и статический резерв. Автономный HTML
проверен как self-contained srcdoc без внешних загрузок. При 1040 переходах
число DOM-элементов после каждого полного цикла оставалось постоянным.

Microsoft Edge, физический кликер, проектор и запуск file:// в браузере
конкретного ноутбука не проверены. Облачный браузер отклонил Fullscreen API.
Первичная серия rAF содержит облачную задержку; стабильные 60 FPS на целевом
ноутбуке не подтверждены. Эти ограничения подробно указаны в отчете.
