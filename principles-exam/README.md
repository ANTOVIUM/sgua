# Цивилист: принципы гражданского права

Публичная контрольная работа: https://antovium.github.io/sgua/principles-exam/

Статический интерфейс без исполняемых зависимостей. Серверный банк, оценивание и таймер находятся в существующем Supabase project `hmdjcxpogdrveddznedx`, отдельная схема `civilist_private`. Другие приложения не изменяются. Публикация - существующий GitHub Actions workflow Pages.

## Преподавателю

Открыть Supabase Dashboard → SQL Editor и выполнить:

```sql
select * from civilist_private.teacher_exam_results order by "Дата" desc;
```

В результатах запроса доступна выгрузка CSV. Время в БД хранится в UTC; Саратов UTC+4.

Открыть подробный разбор всем завершившим работу:

```sql
update civilist_private.exam_settings set show_review = true, updated_at=now() where id;
```

Закрыть разбор: заменить `true` на `false`. По умолчанию разбор закрыт. Закрыть прием новых попыток:

```sql
update civilist_private.exam_settings set is_open = false, updated_at=now() where id;
```

Уже начатые попытки продолжаются до своего срока. `is_open=true` открывает новые попытки. Результаты и ключи недоступны публичным ролям. Доступ преподавателя обеспечивается его учетной записью Supabase. Нет публичного пароля администратора.

Каждая попытка получает случайный вариант и индивидуальный порядок заданий блока I, конфликтов блока II и вариантов выбора. Всего 14 экранов: пять вопросов карты, четыре конфликта на одном экране, два договорных казуса, пять материалов досье, итоговая цепочка. Самостоятельных оцениваемых компонентов больше 14, поскольку сохранены все обязательные элементы задания.

Нет проверки личности без регистрации: ФИО сообщает студент. Код результата позволяет найти серверную запись, но не подтверждает личность. Число переходов в другие окна - диагностическая информация, не доказательство нарушения. Повторное открытие страницы восстанавливает ту же попытку и не перезапускает время.

## Время и сохранение

Срок фиксируется в БД: expires_at=started_at+20 minutes. API блокирует поздние ответы независимо от состояния браузера. Cron раз в минуту завершает истекшие попытки, сохраняя фактическим временем завершения установленный deadline. Локальная очередь не является источником истины. В сложном досье предыдущий ответ фиксируется при открытии следующего материала.

При офлайн-перезагрузке страница ожидает серверной проверки срока. При временной потере связи на открытом экране ответы кешируются. Новые скрытые материалы требуют связи. При закрытом разборе API не возвращает правила оценки, баллы отдельных ответов и объяснения.

## Безопасность

В этом каталоге находятся только публичные файлы. Публикуется современный publishable key. Ни привилегированные ключи, ни серверный банк, ни SQL реализации оценивания в репозитории не хранятся. Единственная RPC - намеренно публичный узкий шлюз, проверяющий 256-битный токен сеанса и срок под блокировкой строки. Прямые разрешения на закрытые таблицы отсутствуют, RLS работает в режиме default deny.
